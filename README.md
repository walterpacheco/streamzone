## Descripción

StreamZone es un clon educativo inspirado en plataformas de streaming como Disney+ y Netflix.  
El proyecto fue desarrollado utilizando HTML5 semántico, Bootstrap 5, CSS personalizado y JavaScript vanilla.

El objetivo principal es construir una interfaz responsive moderna preparada para futuras integraciones con APIs públicas en la Evaluación 2.

---

## Características

- Navbar responsive con Bootstrap 5
- Hero section personalizada
- Diseño responsive mobile first
- Variables CSS personalizadas
- Tipografía web personalizada
- Componentes Bootstrap integrados visualmente
- JavaScript vanilla para interacción DOM
- Flujo Git profesional usando ramas feature, Pull Requests y Code Reviews
